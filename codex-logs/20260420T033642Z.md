Topic: Add Felzenszwalb exact EDT backend to graph_planner FM2 and switch default ESDF mode from FIESTA to Felzenszwalb.

Decisions
- Added a new `graph_planner` distance-field backend `2=esdf_felzenszwalb_2d` alongside existing `0=fmm` and `1=esdf_fiesta_2d`.
- Kept the previous FIESTA-style incremental ESDF backend for comparison and fallback, but changed the default FM2 ESDF backend to Felzenszwalb.
- Implemented Felzenszwalb as a separate full-map EDT class instead of modifying `IncrementalEsdf2D`, so incremental and exact-recompute paths stay independent.
- Updated the default simtest planner config and `shape_assembly_5x10_d2_esdf.sh` wrapper to use backend `2`.
- Left earlier `fm2_gather` ESDF/FMM changes in the worktree untouched; this change only extends `graph_planner`.
