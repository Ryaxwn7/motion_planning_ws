Topic
FM2 gather-cost based replanning trigger

Decisions
- Added a latched scalar FM2 estimated gather cost topic and a latched per-robot arrival-time array topic.
- The estimated gather cost is taken from the mission-specific combined FM2 cost grid at the selected gather index.
- `c_plan_monitor` can now use `replan_growth_metric` values `path_length`, `gather_cost`, `both`, or `off`.
- Default shape assembly YAML and host UI config now select `gather_cost`; launch-file defaults remain `path_length` for compatibility unless config or args override them.
- Existing aborted, rejected/lost, stable-length, and path-length growth triggers were kept; path-length growth now only runs when selected by `replan_growth_metric`.
- Gather-cost growth baseline resets when gather is inactive or all robots are under shape takeover.
