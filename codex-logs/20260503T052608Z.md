Topic
Expose gather cost in monitor logs and replan on empty global plans

Decisions
- `c_plan_monitor` now prints the current estimated gather cost whenever `/fm2_gather/estimated_gather_cost` updates.
- Consecutive empty `GraphPlanner/plan` messages now trigger gather-point recomputation with `/gather_signal=2`.
- Empty-plan replanning is enabled by default with threshold `empty_plan_replan_count: 3`.
- Empty-plan replan events include robot id, empty count, target goal, and latest gather cost in `/gather_replan_event`.
- The prior ABORTED/REJECTED/LOST handling remains unchanged; the new trigger covers cases where move_base stays active/recovering without publishing a final failed result.
