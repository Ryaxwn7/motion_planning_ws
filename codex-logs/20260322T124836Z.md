Topic: Current gather startup path and gather-center source

Decisions
- Clarified that the current default host experiment flow starts gathering from `/shape_assembly/center_goal_cmd`, not from fully automatic fm2_gather center selection.
- Clarified that fm2_gather still retains an internal automatic center-computation path based on map and robot poses.

Findings
- Current host launch uses `publish_goal:=false` and `publish_center_goal_only:=true`.
- fm2_gather subscribes to `/shape_assembly/center_goal_cmd`, republishes the center to `/gather_center`, and does not directly drive move_base in the current strategic mode.
- shape_task_supervisor then subscribes to `/gather_center`, computes shape heading from `/map`, and publishes `/shape_assembly/task`.
- Automatic fm2_gather center computation is still available via `start_compute` / `/gather_signal` and on strategic replan conversion.
