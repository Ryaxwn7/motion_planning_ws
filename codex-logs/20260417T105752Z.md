Topic: Add a 2D FIESTA-style ESDF backend for FM2 distance-field generation and keep FMM fallback.
Decisions
- Added an incremental 2D ESDF implementation inside `graph_planner` and used it only for `FM2_Planner`.
- Kept the legacy first-stage FMM path behind `distance_field_backend=0`; default backend is `1` for `esdf_fiesta_2d`.
- Treated `NO_INFORMATION` as occupied in the ESDF fused occupancy path.
- Disabled dynamic-obstacle uncertainty-kernel application when the ESDF backend is active; dynamic obstacles now affect the fused occupancy directly.
- Rebuilt the second-stage FM2 propagation and ETA extraction unchanged so path generation and `arrival_time` stay on the existing interface.
- Added a gtest that compares ESDF initialization and insert/delete updates against a brute-force EDT reference.
