Topic
Fix host-side FM2 gather not dispatching move_base goals after `/gather_signal=2`.
Decisions
- User confirmed they were already clicking `Send Gather=2`; the previous UI-only shape-publish fix was not the root cause.
- Root cause for the reported symptom was host-side launch default `publish_goal=false`: `/gather_signal` could compute `/gather_center` and produce `/shape_assembly/task`, but `fm2_gather` skipped `publish_goals()` so robots received shape/center without move_base goals.
- Changed `formation_host.launch` default `publish_goal` to `true` to match the direct-center navigation policy.
- Added `publish_goal` arg passthrough in `shape_assembly_host.launch`.
- Made host UI `Start Host` explicitly pass `publish_goal:=true`.
