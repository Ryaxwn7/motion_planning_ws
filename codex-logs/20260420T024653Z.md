Topic: Add EDT/ESDF-style obstacle distance field backend to fm2_gather gather-point computation.

Decisions
- Added a new `distance_field_backend` switch to `fm2_gather`, with `0=fmm` and `1=esdf_edt`.

- Implemented the ESDF backend inside `fm2_gather`'s local `FastMarching2` template by replacing only the first obstacle-distance stage; the second FM2 propagation and existing velocity mapping semantics remain unchanged.
- Used a 2D exact EDT two-pass squared-distance transform adapted from `/home/yxw/rendezvous_benchmark/algorithms/fm2/include/fast_methods/fm2/fm2vel.hpp`.
- Wired the backend selection into all gather solver construction paths, including regular gather, test mode, and `mission=space`.
