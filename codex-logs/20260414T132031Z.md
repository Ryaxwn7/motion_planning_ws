Topic: Add yaw correction to shape_assembly so robots align to the target shape heading after shape takeover.

Decisions
- Kept yaw control inactive during move_base navigation; yaw correction now starts only after `shape_assembly` takes over control.
- Used the existing shared `ShapeTask.shape_heading` / `refer_state.head` as the target final heading in `reference` mode so all robots converge to one common yaw.

- Added yaw-error-based linear slowdown so robots reduce or stop translational motion while large heading error is being corrected.
- Extended existing marker output with current-heading, target-heading, and yaw-error markers instead of changing message schemas.
